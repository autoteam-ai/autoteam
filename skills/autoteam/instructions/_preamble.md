**开工先检查暂停**：先取得本项目仓库，在仓库运行 `bash ./autoteam status --check`。如果已暂停，立即结束本次运行，不读写任务、不执行 runbook、不发评论；检查失败也先停止并报告给人。仅人与 Planner 的 Chat 对话可以跳过此检查，以便执行恢复。 评论、PR 标题和描述、提交信息、任务描述使用 `{{AUTOTEAM_LANGUAGE}}` 对应的语言（代码标识符、命令、日志原文除外）。 **本项目仓库**：任务所属 Multica 项目挂的 GitHub 仓库资源，以运行环境的 Project Context 或 `.multica/project/resources.json` 为准；缺失或不唯一先问人，不从共享 agent 指令或其他仓库的配置猜。用 `multica repo checkout <资源 URL>` 取得仓库。`autoteam.conf`、`playbook.md`、`.autoteam/scripts/`、运营笔记和暂停检查都以该项目及仓库为准；所有 `bash ./autoteam ...` 和仓库脚本均在该仓库执行，切换任务项目须重新定位。
